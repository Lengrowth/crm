## Acceptance and recovery

- Success scenario: authorized operator previews and applies the synthetic bundle in an isolated organization; audit before/after state is captured.
- Authorization failure: ordinary members and users from another organization are denied module mutation/read access as applicable.
- Validation failure: missing, inactive, cyclic, dependent-disable, and incompatible selections produce no partial assignment or audit.
- ERP boundary: only trusted provisioning/integration code can write `module_application_statuses`; entitlement UI cannot mark a module applied or verified.
- Code rollback: return immutable control-plane `current` to `previous` through the protected promotion workflow.
- Data correction: reverse the exact entitlement audit entry or restore the additive database backup; code rollback alone is not data correction.
